# راهنمای پروژهٔ سایت علی اسماعیلی

این پروژه با **Astro + React + TypeScript** ساخته شده است. صفحات موقع build به HTML تبدیل می‌شوند؛ جابه‌جایی بین صفحات با `ClientRouter` حس SPA دارد. روی هاست به سرور Node.js نیاز ندارد.

## اجرا

Node.js نسخهٔ ۲۲.۱۲ یا بالاتر:

```sh
npm ci
npm run dev
```

خروجی آمادهٔ هاست:

```sh
npm run check
npm run build
npm run audit:build
```

محتوای پوشهٔ `dist` را روی هاست استاتیک قرار بده. هر مسیر صفحهٔ HTML خودش را دارد؛ تمام آدرس‌ها را به صفحهٔ اصلی rewrite نکن. برای دامنهٔ اصلی، فایل `.env.example` را به `.env` کپی کن و `SITE_URL` را تنظیم کن.

## تغییر محتوا

| چه چیزی؟                                      | کجا؟                                          |
| --------------------------------------------- | --------------------------------------------- |
| اطلاعات شخصی، شبکه‌های اجتماعی، مهارت و تجربه | `src/data/site.ts`                            |
| پروژهٔ جدید                                   | فایل Markdown جدید در `src/content/projects/` |
| پادکست و اپیزودها                             | `src/content/podcasts/`                       |
| پروژه‌های Lab و لینکشان                       | `src/content/lab/`                            |
| رنگ، فونت و ظاهر                              | `src/styles/global.css`                       |
| رزومهٔ قابل دانلود                            | `public/Ali-Esmaeili-CV.pdf`                  |

برای اضافه‌کردن پروژه یا پادکست، از یک فایل موجود کپی بگیر و محتوا و نام فایل را تغییر بده. نام فایل تبدیل به slug می‌شود؛ مسیر جدید بعد از build خودکار ساخته می‌شود. قالب کامل frontmatter در راهنمای انگلیسی است.

## بخش رسانه

برای هر دو پادکست صفحهٔ اختصاصی با معرفی و موضوعات ساخته شده است. لینک پلتفرم و فایل صوتی واقعی در اختیار نبود، بنابراین پخش‌کنندهٔ نمایشی و اپیزود ساختگی اضافه نشده است.

با افزودن `listenUrl` و آرایهٔ `episodes` به فایل پادکست، لینک شنیدن و اپیزودها نمایش داده می‌شوند. هر اپیزود می‌تواند `title`، `description`، `audioSrc` و `url` داشته باشد. فایل صوتی فقط هنگام استفاده بارگذاری می‌شود.

## سبک‌بودن سایت

- سه تصویر پس‌زمینهٔ مشترک، هرکدام در سه اندازه و دو فرمت AVIF و WebP.
- مرورگر فقط اندازه و فرمت مناسب را دریافت می‌کند.
- نسخه‌های AVIF دسکتاپ حدود ۳۱ تا ۴۲ کیبی‌بایت هستند.
- متن‌ها و دکمه‌ها HTML هستند و داخل تصویر قرار ندارند.
- صفحهٔ اصلی React ندارد؛ فقط فیلتر پروژه‌ها و فرم تماس React دارند.
- فونت‌ها محلی‌اند و ویدیو یا موتور سه‌بعدی سنگین وجود ندارد.
- تصاویر اصلی PNG در خروجی سایت قرار نگرفته‌اند.

برای تصویر جدید، آن را در `assets-originals/` بگذار و `npm run assets:optimize` را اجرا کن. تصاویر بهینه‌شدهٔ فعلی همراه پروژه هستند؛ برای اجرای سایت نیازی به فایل‌های اصلی نیست.

## فرم تماس

فرم، پیش‌نویس ایمیل را در برنامهٔ ایمیل باز می‌کند. ارسال مستقیم از سرور انجام نمی‌دهد. بعداً می‌توان آن را به یک endpoint واقعی وصل کرد.

## بررسی انجام‌شده

بررسی نوع‌ها و محتوا، build تولید و بررسی لینک‌ها و حجم فایل‌ها انجام می‌شود. گزارش‌ها در `docs` هستند. تست بصری و تعاملی در مرورگر در محیط ساخت در دسترس نبود؛ امتیاز Lighthouse ادعا نشده است.
